# Spot On!

A lively multiplayer party game about knowing your friends—or being wildly confident that you do.

**[Play Spot On!](https://spot-online.web.app/)**

## How it works

One player enters the spotlight while everyone else secretly chooses the cards they think that player would like best. The spotlight player ranks the anonymous choices, points are awarded, and the remaining cards move around the group. Everyone gets a turn in the spotlight before the next game begins.

## Features

- Live rooms for 3–6 players
- Mobile-first, single-page gameplay
- Touch-friendly card selection and ranking
- Animated reveals, score updates, and live leaderboards
- A once-per-game fresh-hand shuffle
- Configurable session length
- Optional Pop Culture, Pokémon, and India expansions
- Automatic session restoration after refreshing or briefly disconnecting
- Persistent rooms with host migration when someone leaves

No accounts are required—create a room, share its five-character code, and start guessing.
